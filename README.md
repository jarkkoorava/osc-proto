# OSC Manifest

A prototype of a skydiving manifest program for Oulu Skydive Center.

## Technology stack

- React and TypeScript
- Vite
- Tailwind CSS
- dnd-kit for drag and drop
- Browser localStorage for demo data
- Oxlint and Playwright for linting and testing

## Local setup

Install Node.js 22.14+ and npm, then run:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal.
